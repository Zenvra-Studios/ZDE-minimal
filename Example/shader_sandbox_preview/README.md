# ZDE Shader Sandbox Examples

Folder ini berisi kumpulan shader contoh (*presets*) yang kompatibel dengan **Shader Sandbox Panel** di ZDE (Zenvra Development Environment).

| [`02_raymarching_3d.frag`](./02_raymarching_3d.frag) | 3D Raymarching SDF | 3D Torus & Sphere berputar dengan rotasi matriks & lighting |

## 🚀 Cara Menjalankan di ZDE

1. Buka file shader (`.frag` atau `.glsl`) mana saja dari daftar di atas di editor ZDE.
2. Panel **Shader Sandbox** di sisi kanan editor akan terbuka secara otomatis dan langsung me-render visual shader secara real-time.
3. Anda dapat mengedit kode, mengubah parameter warna/kecepatan, dan hasilnya langsung ter-sinkronisasi (*auto-synced*) tanpa perlu me-reload aplikasi.
